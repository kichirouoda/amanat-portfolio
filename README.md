# Amanat Nur Rochman Portfolio

A static, responsive backend developer portfolio built with HTML, CSS, and vanilla JavaScript. No build process or external dependency is required.

## Preview locally

From this folder, run one of the following commands:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `amanat-portfolio`.
2. Upload all files and folders from this directory to the repository root.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will show the public website URL after deployment completes.

All paths are relative, so the site works both for a user Pages repository and a project Pages repository.

## Update content

- Edit page content in `index.html`.
- Edit colors and layout tokens at the top of `styles.css`.
- Replace `assets/Amanat-Nur-Rochman-Resume.pdf` when a newer résumé is available; keep the same filename to preserve the download link.
